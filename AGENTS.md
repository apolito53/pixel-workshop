# Working instructions

When Anthony requests changes, finish the implementation and appropriate checks,
then commit and push directly to `main`. This is the normal delivery workflow;
do not create a pull request unless Anthony explicitly asks for one.

Routine edits, commits, and pushes within the requested work are authorized.
Do not ask for another conversational approval. If a platform approval review
blocks an action, report that specific blocker and follow its requirements.

Preserve unrelated work and existing features. Verify the intended repository
and current remote head before updating `main`; never overwrite concurrent work.
